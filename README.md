Bookmarklet

Uma página HTML5 simples para disponibilizar um Bookmarklet de forma rápida, permitindo copiar o código ou arrastá-lo diretamente para a barra de favoritos do navegador.

Recursos

- Interface Dark Total.
- Design minimalista inspirado em interfaces modernas.
- Ícones utilizando Lucide.
- Animações e interações de toque.
- Botão para copiar o Bookmarklet.
- Área própria para arrastar o Bookmarklet para a barra de favoritos.
- Tutorial de configuração passo a passo.
- Compatível com navegadores modernos.
- Layout responsivo para dispositivos móveis.

Como usar

1. Abra o "index.html" no navegador.
2. No computador, ative a barra de favoritos usando "Ctrl + Shift + B".
3. Arraste a caixa Meu Bookmarklet para a barra de favoritos.
4. Alternativamente, clique em Copiar código.
5. Crie um novo favorito.
6. Apague a URL existente.
7. Cole o código do Bookmarklet no campo de URL.
8. Salve o favorito.
9. Clique no favorito quando quiser executar o Bookmarklet.
